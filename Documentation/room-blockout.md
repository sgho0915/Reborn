# 3단계 — 원룸 블록아웃

## 실행 및 검토

- 씬: `Assets/Reborn/Scenes/RoomBlockout.unity`
- Play → Game 화면 클릭 → WASD 이동 / 마우스 시선 / Esc 커서 해제.
- Hierarchy의 `Room layout review` 선택 → Inspector의 Layout 변경으로 Reality / Opening / Exit 비교.
- Play 중 변경한 배치는 종료 시 원복. 저장된 기본 상태는 Reality.
- 가구 비례, 통로 폭, 문 위치 검토 단계. 사실적인 모델·텍스처·시간별 조명·소리·퍼즐은 미포함.

## 승인 컨셉과 배치 기준

저장소 밖 `../../art/concepts/v03/01-room.png`의 현실 원룸과 `v07-room-timeline/README.md`의 공간 불변 조건을 기준으로 구성.
주방·세탁기·냉장고·침대는 입구에서 보아 왼쪽, 책상·수납·옷걸이는 오른쪽, 창은 안쪽 벽에 배치.
생성 이미지에 치수가 없으므로 아래 수치는 플레이 검토용 제안이며 확정 도면이 아님.

기존 `../../docs/development/05-assets-and-direction.md`의 4.8 × 4.2m 및 좌표는 승인 컨셉 이전 시작값.
이 블록아웃에서는 좁고 긴 구조로 조정. 후속 원룸 제작은 본 문서의 좌표를 사용하되 사용자 검토 후 확정.
기존 기획 문서 원문은 변경하지 않음.

| 항목 | 현재 기준 |
| --- | --- |
| 단위 / 실내 | 1 Unity 단위 = 1m / 폭 3.4 × 깊이 5.4 × 높이 2.5m |
| 원점 / 방향 | 입구 벽 바닥 중앙 / +Z 창, −X 주방, +X 책상 |
| 실제 현관 | z=0, x=0.425 중심, 폭 1.05m |
| 기억의 문 | 오른쪽 벽, z=0.87 중심, 폭 0.9m. 현재는 통과 불가 표시 모델 |
| 책상 | x=1.35, z=4.3, 높이 0.74m |
| 침대 | x=−1.12, z=4.4, 폭 1.08 × 길이 1.95m |
| 현실 서랍장 | x=1.38, z=3.05, 폭 0.5 × 높이 0.7 × 깊이 0.45m |
| 주관적 서랍장 | 폭 1.25 × 높이 2.1 × 깊이 0.65m, 세 서랍 |
| 서랍장 시작 → 끝 | (0.45, 0, 0.45) → (−0.98, 0, 0.45), 같은 크기로 1.43m 이동 |
| 중앙 통로 | 주 검증 경로 x=0.1, z=1.15~4.9. 침대·의자 사이 약 1.04m |
| 플레이어 | 기존 FirstPersonPlayer 프리팹 재사용, 눈높이 1.6m / FOV 60 / 이동 1.6m/s |

## 상태별 차이

| 상태 | 구성 |
| --- | --- |
| Reality | 작은 서랍장, 실제 현관 닫힘, 기억의 문 숨김 |
| Opening | 큰 서랍장이 실제 현관 차단, 작은 서랍장 숨김, 기억의 문 표시 |
| Exit | 동일한 큰 서랍장이 옆으로 이동, 실제 현관 개방, 기억의 문 유지 |

벽·주요 가구·창의 위치는 세 상태에서 동일. Exit는 문짝과 서랍을 숨겨 동선만 검토하며, 문 여는 회전·꺼낸 서랍 적재·레버·캐스터·이동 애니메이션은 후속 구현.
세탁기·셔츠·우산·일기·달력 등은 크기와 위치 확인용 단순 도형. 빨래 건조대와 생활 소품 세부 배치는 후속 모델 교체 때 추가.
복도는 출구 통과 확인용 막힌 짧은 구간. 기억의 문 뒤 공간이나 씬 전환은 미구현.
노출 고정 EV100 8 및 임시 실내 보조광 사용. 최종 자연광·간접광·색보정 또는 성능 검증 결과로 해석하지 않음.

## 검증

Unity 6000.6.0f1의 실제 Play 모드에서 `Reborn.Editor.RoomBlockoutValidation.Run()` 실행.

- 세 상태의 중앙 이동, 책상 앞 접근, 창가 접근 및 왕복 통과.
- Reality의 닫힌 현관 충돌 통과.
- Opening의 큰 서랍장 차단 충돌 통과.
- Exit에서 현관을 거쳐 복도까지 이동 통과.
- 검사는 실제 CharacterController.Move를 사용하고 종료 후 배치·플레이어 위치 복원.
- 실제 게임 카메라 캡처로 배치 및 노출 검토. 사용자의 체감 공간 검토는 대기.
- Windows/macOS 배포 빌드, 가구 이동 중 충돌, 퍼즐 접근 거리 및 최종 그래픽 성능은 이번 검증 범위 밖.

생성 도구 `Reborn/Create Room Blockout`은 기존 씬 덮어쓰기를 거부하며 새 씬을 별도로 생성·저장한 뒤 이전 씬 복원. 현재 씬을 수정하려면 일반 Unity 편집 사용.
