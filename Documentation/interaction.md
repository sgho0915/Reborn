# 4단계 — 사물 조사 기초

## 실행

1. `Assets/Reborn/Scenes/RoomBlockout.unity`에서 Play 후 Game 화면 클릭.
2. 일기장·프린터·달력·우산 중 하나에 접근하고 화면 중앙으로 조준.
3. `E 조사` 안내가 나타나면 E로 설명 열람.
4. Esc 또는 닫기 버튼으로 닫은 뒤 화면을 클릭해 탐색 재개.

카메라에서 표면까지 2m 이내의 첫 번째 충돌체만 판정. 가구나 벽에 가리거나 거리를 벗어나면 조사 불가.
조사 화면이 열린 동안 이동·시선·커서 재잠금 중지. 닫기 후 자동으로 시점이 움직이지 않도록 커서 해제 유지.
소품이 비활성화되거나 삭제되면 조사 종료. 앱 전환 중에는 조사 화면 유지, 탐색 커서는 기존 조작 규칙에 따라 해제.

## 구현 범위

- `InspectableObject`: 안정적 ID, 표시 이름, 설명 데이터.
- `InteractionController`: 조준·가림 검사, E 입력, 조사 패널, 닫기.
- `FirstPersonController`: 조사 문맥에서 조작 차단. 기존 이동 수치·마우스 감도 유지.
- 네 소품은 원룸 씬에만 연결. 기존 이동 테스트 씬과 공용 플레이어 프리팹 구성 유지.
- 조사 설명은 검증용 임시 문구. 실제 원고·원문 이미지와 연결 전 단계.
- 간단한 IMGUI 패널 및 운영체제 한글 글꼴 사용. 최종 UI와 배포용 글꼴 에셋은 별도 제작.
- 모델 확대·회전, 소품 운반·사용, 일기 페이지, 퍼즐 진행, 저장, 사운드는 미구현.

`Reborn/Setup Room Interactions`는 저장된 원룸 씬에서 컴포넌트를 연결하는 개발 도구. 재실행 시 네 소품 설명을 검증용 문구로 다시 설정하므로 원문 작업 후 실행 금지.

## 검증 결과

Unity 6000.6.0f1 Play 모드에서 `Reborn.Editor.InteractionValidation.Run()` 실행:

- 통로에서 일기장 선택 및 조사 시작 통과.
- 임시 장애물이 시야를 막으면 조준과 조사 실행 모두 거절.
- 조사 중 이동·시선 변경 차단 및 중복 조사 거절.
- 닫기 후 입력 잠금 해제 및 조사 대상 초기화.
- 사거리 밖 조사 거절.

별도 실시간 검사로 프린터·달력·우산의 통로 접근 및 조준 가능 확인.
기존 `RoomBlockoutValidation.Run()`의 세 상태 이동·출구 검증 통과.
실제 키보드 E/Esc와 닫기 버튼의 사용자 조작 체감 및 UI 시각 검토는 대기.
Windows/macOS 배포 빌드와 최종 UI 검증은 미실시.
